# Госзакупки - выжимка контрактов из PDF

FastAPI-сервис, который принимает PDF-контракт с сайта госзакупок и через
локальную LLM (Ollama, модель `llama3.1`) возвращает структурированную
выжимку: сумму контракта, сроки, требования к исполнителю и штрафы.

Замечания к проекту:
• Это не комерческий проект а тестовое, поэтому многое делалось на скорую руку.

• Для тестов в проекте лежит PDF файл, можете использовать его или свой любой файл.

• env файл я убирать с Git не стал, для удобства отладки.

• Версия ламы у вас должна быть установлена заранее.

• Развертку через докер я не делал по однйо простой причине - скачивание ламы в контейнер займет много времени. Она под 5GB весит.

• Получение результата через эндпоинт занимает примерно минуты 3, так как это бесплатная модeль.

• Для проверки рекомендую использовать Swagger который идет в FastAPI из коробки. Достаточно ввести в браузере http://0.0.0.0:8000/docs после запуска проекта.

• Для коммерческого решения необходимо было бы создать конфиги с переводами, тут же этого нет.

• Для загрузки зависимостей в комерческом решении лучше было бы использовать Poetry. Но тут я упростил до простого текстового файла с зависимостями.

## 1. Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Запуск Ollama и модели

```bash
ollama serve
ollama pull llama3.1
```

## 3. Настройка

```bash
cp .env.example .env
```

## 4. Запуск сервиса

```bash
uvicorn app.main:app --reload --port 8000
```

Документация Swagger: http://localhost:8000/docs

## 5. Пример запроса

```bash
curl -X POST http://localhost:8000/summarize \
  -F "file=@contract.pdf"
```
